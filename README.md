# Landing Page — Caique Torres

Uma aplicação web moderna e responsiva desenvolvida com HTML, CSS e JavaScript, projetada para apresentar meu portfólio, destacar minhas habilidades em desenvolvimento web e demonstrar, na prática, o que sei fazer na área de tecnologia.

---

## Demonstração

[Clique aqui para acessar minha Landing Page](https://caique-torres.github.io/Landing-Page/)

---

## Funcionalidades

- **Apresentação Pessoal:** Seção Hero dedicada à minha apresentação profissional, destacando meus conhecimentos e objetivos na área de tecnologia.
- **Habilidades e Tecnologias:** Exibição das minhas competências em HTML, CSS, JavaScript, React, Git, GitHub e integração com APIs.
- **Projetos em Destaque:** Apresentação de projetos desenvolvidos para demonstrar minhas habilidades e experiências práticas em programação.
- **Formulário de Contato:** Canal de comunicação para facilitar o contato com recrutadores, clientes e possíveis parceiros.
- **Design Responsivo:** Interface adaptável para celulares, tablets e desktops, garantindo uma boa experiência em diferentes dispositivos.
- **Navegação Intuitiva:** Menu de navegação com rolagem suave e menu lateral para dispositivos móveis.
- **Interface Moderna:** Design desenvolvido para apresentar meu trabalho de forma organizada, profissional e visualmente atrativa.

---

## Tecnologias Utilizadas

- **HTML5:** Estruturação e organização do conteúdo.
- **CSS3:** Estilização, animações e criação de layouts responsivos.
- **JavaScript (ES6+):** Implementação de interatividade e funcionalidades dinâmicas.
- **React:** Desenvolvimento de interfaces e componentes reutilizáveis.
- **Git e GitHub:** Versionamento, organização e gerenciamento de código.
- **FormSubmit:** Integração do formulário de contato para envio de mensagens por e-mail.

## O que sei fazer

- Desenvolver páginas web modernas e responsivas.
- Criar interfaces intuitivas e adaptáveis a diferentes dispositivos.
- Implementar funcionalidades interativas utilizando JavaScript.
- Desenvolver interfaces com React e componentes reutilizáveis.
- Consumir APIs e integrar serviços externos.
- Utilizar Git e GitHub para versionamento e gerenciamento de projetos.
- Publicar projetos web utilizando o GitHub Pages.
- Aplicar boas práticas de organização, usabilidade e estruturação de código.

## Objetivo

Este projeto foi desenvolvido com o objetivo de apresentar meu perfil profissional, demonstrar minhas habilidades em desenvolvimento web e reunir meus principais trabalhos em um único lugar.

A landing page também representa minha evolução na área de tecnologia, colocando em prática conhecimentos de desenvolvimento front-end, design responsivo, experiência do usuário (UX) e organização de código.

Além disso, o projeto busca ampliar minha presença profissional, facilitar o contato com recrutadores e clientes e abrir oportunidades para novos projetos e parcerias.
